CodeNote プライバシーポリシー

制定日: 2026年11月10日

CodeNote (以下「本アプリ」) の開発者 (以下「開発者」) は、本アプリにおける利用者の情報の取り扱いを以下のとおり定めます。

1. 開発者が収集する情報

開発者は、利用者の個人情報、チャットの内容、ファイルなどを収集しません。本アプリは開発者のサーバーを持たず、広告・アクセス解析・トラッキングの仕組みも使用していません。

2. 端末に保存する情報

  • 保存したモジュール (Python のコード・名前・説明)、許可リスト (ドメイン名・登録したファイル): 端末内に保存します。
  • Claude の APIキー、スクリプト用の API キーの値: 端末の Keychain に暗号化して保存します。iCloud バックアップや他の端末には移行されません。
  • スクリプト用の API キーの名前・説明・送信先のドメイン、AI へのデータ送信への同意の状態

チャットの内容と添付したファイルは保存せず、アプリを閉じると消えます。これらの情報は本アプリを削除すると端末から消去されます。

3. 外部の AI サービスへの送信

本アプリは、利用者が同意した場合に限り、チャットで質問したときに次の情報を Anthropic, PBC が提供する Claude API に送信します。送信には利用者自身の APIキーを使用し、開発者のサーバーは経由しません。

  • 質問の文章と、添付したファイル (PDF・CSV など) の内容
  • Claude が書いたコードと、その実行結果 (出力・エラー)
  • 許可リストのドメイン名・ファイル名、保存したモジュールの名前・説明・コード、スクリプト用の API キーの名前・説明 (API キーの値は送信しません)

送信された情報は Anthropic のプライバシーポリシーと利用規約に従って取り扱われます。同意は本アプリの「設定」→「AI の利用」からいつでも取り消せます。取り消した場合、チャットは利用できなくなります。

4. スクリプトによる通信

AI が書いたスクリプトは、端末内の隔離された環境で実行され、本アプリのデータや Keychain には触れられません。スクリプトが通信できるのは、利用者が許可リストに登録したドメインだけです。その際、スクリプトが組み立てた内容と、そのドメイン用に利用者が登録した API キーの値が、登録したドメインに送信されます。スクリプトは実行前に利用者が確認します。

5. 他の利用者とのモジュールの受け渡し

利用者が QR コードやファイル (AirDrop・メッセージなど) でモジュールを送る場合、そのモジュールのコード・名前・説明が相手に渡ります。開発者のサーバーは経由しません。

6. 第三者への提供

開発者は利用者の情報を保有しないため、第三者に提供することはありません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。AI に送信する情報の範囲を変える場合は、本アプリ内で改めて同意をお願いします。
