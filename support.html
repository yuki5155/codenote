CodeNote サポート

質問に合わせて AI が Python のコードを書き、iPhone の中の隔離された環境で実行して答えるアプリです。

はじめに必要なもの

チャットには、Claude の APIキーが必要です。

  1. Claude Console でアカウントを作り、支払い方法を登録します。
  2. 「API Keys」から APIキーを作成してコピーします。
  3. CodeNote の「設定」タブに貼り付けて保存します。

利用料は Anthropic から利用者のアカウントに請求されます。

よくある質問

AI が書いたコードは安全ですか？

コードは実行前に必ず確認画面に表示され、書き換えたり断ったりできます。実行は iPhone の中の隔離された環境 (ブラウザの仕組みを使った Python) で行い、アプリのデータや Keychain には触れられません。15 秒で自動的に止まります。

インターネットのデータを使いたい

「許可リスト」タブでドメインを登録すると、スクリプトからそのドメインのデータを取得できます。登録していないドメインとは通信できません。

外部の API を使いたい

チャットで「〇〇の API を使いたい」と頼むと、AI が API キーの入れ物を作ります。値は「設定」→「API キー」で入力してください。値は AI にもスクリプトにも見えず、登録した送信先への通信にだけ使われます。

PDF や CSV を読ませたい

チャットの入力欄の 📎 から添付できます。Excel で書き出した CSV (Shift_JIS) にも対応しています。

作った関数を保存・共有したい

チャットで「この関数を保存して」と頼むと、ライブラリに保存され、以後のスクリプトから使えます。「ライブラリ」タブから QR コードやファイル (AirDrop など) で他の人に送れます。

AI に送るデータを確認したい

「設定」の「AI の利用」と、プライバシーポリシー をご覧ください。
